# Capturas de Pantalla de la Aplicación Preventas

Ubicación para las imágenes referenciadas en el [Manual del Usuario](../manual_usuario.md).

Las imágenes deben tener los siguientes nombres de archivo (formato PNG recomendado):

| Archivo | Pantalla / Sección |
| :--- | :--- |
| `01_login_online.png` | Pantalla de Login Online (con organización fija y campos de usuario/contraseña). |
| `02_login_offline.png` | Pantalla de Login en Modo Offline (con banner de advertencia y opciones biométrica/sesión guardada). |
| `03_autenticacion_biometrica.png` | Pantalla de Autenticación Biométrica (lector de huella digital táctil). |
| `04_menu_principal.png` | Menú lateral (Drawer) de navegación principal. |
| `05_mis_pedidos.png` | Pantalla "Mis Pedidos" (listado de pedidos con filtros y badges de sincronización). |
| `06_detalle_pedido.png` | Detalle del pedido con desglose de ítems, totales y estado. |
| `07_wizard_paso1_cliente.png` | Wizard Nuevo Pedido - Paso 1: Selección de Cliente y Condición de Venta. |
| `08_wizard_paso2_productos.png` | Wizard Nuevo Pedido - Paso 2: Carga de Productos y Totales. |
| `09_wizard_paso3_confirmacion.png` | Wizard Nuevo Pedido - Paso 3: Selección de Reparto y Confirmación. |
| `10_catalogo_productos.png` | Pantalla de Catálogo de Productos con filtros por categorías y buscador. |
| `11_mis_clientes.png` | Pantalla "Mis Clientes" (listado de clientes con buscador y botón Crear). |
| `12_detalle_cliente.png` | Pantalla de Detalle de Cliente (cajas de información comercial y fiscal). |
| `13_mis_repartos.png` | Pantalla "Mis Repartos" (listado de repartos por estado y zona). |
| `14_faltantes.png` | Pantalla de "Faltantes" (productos no entregados con observaciones y fechas relativas). |
